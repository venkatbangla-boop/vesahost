## B. Checkpoint completion score - fixed formula

Accepted gate counts: TNA t / 13, PPM p / 11, AQL a / 13, Shared s / 10.

```text
TNA%     = ROUND(100 * t / 13)
PPM%     = ROUND(100 * p / 11)
AQL%     = ROUND(100 * a / 13)
Shared%  = ROUND(100 * s / 10)
OVERALL% = ROUND(30 * t / 13 + 30 * p / 11 + 30 * a / 13 + 10 * s / 10)
BALANCE% = 100 - OVERALL%
```
